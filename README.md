# Space View

Space View is a community-maintained distribution of the NeonPlan 3D Home Assistant integration. It is not an official Home Assistant project.

## Install with HACS

1. In Home Assistant, open HACS and choose **Integrations**.
2. Open the menu and choose **Custom repositories**.
3. Add `DarkDevX/ha-spaceview` with the **Integration** category.
4. Find **Space View**, download it, and restart Home Assistant if prompted.

## Updates

To update, open **HACS → Integrations**, select **Space View**, and install an offered update. Restart Home Assistant if prompted.
